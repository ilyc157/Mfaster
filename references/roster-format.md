# 报单文本：能认什么、不能认什么

`scripts/roster.py` 把群聊里的报单转成结构化名单。它是**确定性兜底**，不是主解析器：
认不出的事情一律记 warning，交给对话里的人确认，绝不静默丢单。

---

## 支持的写法

| 写法 | 例子 | 解析结果 |
| --- | --- | --- |
| `@昵称` 前缀 | `@张三 板烧鸡腿堡套餐 x1` | 人=张三，套餐 ×1 |
| `昵称：` 前缀 | `李四：巨无霸 + 中薯 + 可乐` | 人=李四，三件 |
| `昵称 ` 空格前缀 | `王五 麦辣鸡腿堡套餐` | 人=王五 |
| 时间戳 | `【20:31】@张三 板烧 x1` | 剔除时间戳 |
| 列表符号 | `1. 张三 巨无霸×2` | 剔除 `1.` |
| 中文数量 | `两个麦香鱼` / `1份薯条` / `2杯可乐` | 正确取数 |
| 后缀数量 | `巨无霸x2` `巨无霸×2` `巨无霸*2` | ×2 |
| 前缀数量 | `2份薯条` | ×2 |
| 独立数量 | `麦辣鸡腿堡套餐 x1` | `x1` 回填前一项，不当成菜 |
| 括号备注 | `板烧鸡腿堡套餐 去冰` | 餐品 + 备注「去冰」 |
| `1+1随心配` | `1+1随心配` | 数字间的 `+` 不切分 |
| 泛称 | `赵六：随便` | `intent=any`，由规划器指派 |
| 预算行 | `预算 200` | 写进 `budget`，不进任何人的单 |
| `我` | `我 麦乐鸡10块` | 人=`--me` 指定的人，没给则记 `__ME__` |

分隔符：空格、`、`、`,`、`，`、`/`、`+`、`；`、`|`。

## 数量与规格的边界

`麦乐鸡10块` 里的 10 说的是**盒装规格**，不是 10 盒。处理方式：

1. 先找菜单里名字带同样数字的规格款（`麦乐鸡4块`、`心形薯饼8块`）；
2. 找到就把数量收回 1；
3. 找不到保留 10，并在卡片上挂一句提醒——因为这时候它最可能是误会。

宁可挂提醒，不要替用户改数量。

## 备注只认受控词表

```
不要/不加/去掉/少/多/加/换 + 冰 糖 酱 菜 葱 洋葱 香菜 芝士 奶 番茄酱 酸黄瓜 生菜 吸管 餐具 辣椒 辣
无糖 去冰 少冰 多冰 常温 零度
```

**为什么必须用受控词表**（都是实测踩出来的）：

1. 把裸「无」当备注词，`巨无霸` 会被拆成 `巨` + 备注 `无霸`。
2. 用泛化的 `去[^\s]{1,3}`，`去冰可乐` 会被整串吞成备注，丢掉「可乐」这道菜。

整段像备注的（`不要可乐要无糖的`）会挂到**前一项**上，不会单独变成一道菜。

## 忌口与状态

从本人的原话里识别，参与筛选，也写进卡片依据：

| 类型 | 触发词 | 效果 |
| --- | --- | --- |
| 忌口 | `不吃/不要/不能吃/忌/过敏/不碰/讨厌` + 辣/牛肉/猪肉/肌肉/海鲜/香菜/奶/咖啡/冰 | `avoid` 列表，配餐时过滤 |
| 轻食 | `减肥/减脂/控卡/热量低/轻食/不太饿/不饿/少吃` | `light=True`，文案与默认选择更保守 |

## 泛称（「随便」）

识别的整段匹配词表（去掉「来个/吧/了点」这类前后缀后）：

```
随便 都行 都可以 随意 无所谓 你定 你们定 你看着办 看着办 不挑 啥都行 什么都行
任意 听你的 随你 我不挑 你选 帮我选 来啥吃啥 给啥吃啥 安排 随便安排 都成
```

- `随便来个巨无霸` **不是**泛称，是「巨无霸」。
- 同一行连续泛称会合并成一单（取较大数量）。
- 这个人已经有具体餐品时，后面那句「随便」当语气，不再单独成一单。

## 已知边界（交给对话里的人）

脚本认不出这些，会记 warning 或直接留空，由模型回头问：

- 一句话里报了好几个人：`张三李四都要巨无霸`
- 指代：`和昨天一样`、`老规矩`、`加一个那个`
- 门店黑话与地方叫法（可在 `planner.ALIASES` 里补）
- 一段里同时含餐品与规格：`大杯可乐去冰少糖`（备注能取到，杯型要靠菜单匹配）

`warnings` 里出现下面这两类，**必须回去问用户**，不许自己拆：

- `「XXX」看起来像一句话里报了好几个人`
- `YYY 一个人点了 N 项，确认是不是把别人的单也算进来了`
